# Research

The first deliverable of this project lands here as a pull request, not as a message.

A research note in this folder should answer, in whatever order makes sense:

- **Who** pays, and what they pay for today.
- **What** they currently do instead, and where that breaks down.
- **Why AI changes it** — the specific job it does better, not that it exists.
- **What the smallest thing worth building is**, and what it deliberately leaves out.
- **What it would cost to run**, including any third-party inventory or data.
- **What would have to be true** for this to be wrong.

Name the file after the question it answers, not after the date. One note per question.

Sources go inline as links. A claim without a link is an opinion, which is fine as long as it is
labelled as one.
