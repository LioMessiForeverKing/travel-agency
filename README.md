# travel-agency

A travel product for people who would rather pay someone than plan. What it actually is has not
been decided — that is deliberate, and the first ticket is the research that decides it.

## Status

Scaffold only. A Next.js app that runs, a set of rules that hold, and an empty `docs/research/`
waiting for the first deliverable. There is no product code yet.

## Run it

```bash
npm install
npm run dev
```

Then http://localhost:3000.
